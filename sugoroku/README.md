# 制限すごろく — 運営ツール

リアル交渉ゲーム「制限すごろく」の運営ツール一式。ビルド不要の静的ファイルです。

- **集計ツール**: https://tools.puzzliar.jp/sugoroku/ （GM用。秘匿台帳・定員シャッフル・投票入力・開票・周回／％奪取・最終結果）
- **発表ツール**: https://tools.puzzliar.jp/sugoroku/display.html （プロジェクター用。公開情報のみ表示）
- **ルール説明**: https://tools.puzzliar.jp/sugoroku/display.html?rules （集計ツールなしで単独進行）

ルールの出典：Google Drive「制限すごろく」フォルダの `ライアーゲーム：制限すごろく.pptx`（2025-09-19版）。
開発元のリポジトリは `puzzliar/limited-dice`（ルールエンジンのテストはそちらで `npm test`）。

## 使い方

ビルド不要の静的ファイルです。同じPC・同じブラウザで2つのウィンドウを開いて使います。

```sh
python3 -m http.server 8000   # リポジトリ直下で実行
# → http://localhost:8000/sugoroku/ を開く（集計ツール）
```

1. 集計ツールで参加人数（12〜15人）と名前を入力し、「番号・駒をランダムに割り当て」→「ゲーム開始」。
2. 「発表画面を開く」で発表ツールを別ウィンドウで開き、プロジェクター側に移して `F` キー（または右下のボタン）で全画面にする。
3. ゲーム開始前に、発表画面パネルの「ルール説明」でルール説明スライドを進行する（下記）。
4. 各ターンはステッパーに沿って進める。
   1. **定員公開**：「シャッフルして公開」（物理的にシャッフルした場合は手動入力も可）
   2. **アイテム宣言フェーズA**：公開宣言された順位入れ替えカードを入力
   3. **同時提出フェーズ**：投票用紙の「進む数」と枠数変更カード（数字ごとの枚数）を入力。集計プレビューがリアルタイムで更新される
   4. **開票 → 周回処理・％奪取**：周回者・ボーナス・％奪取権が自動判定される。宣言を宣言順に入力すると判定結果（予定）が表示され、「ターンを確定」で反映
5. 15ターン確定後、最終結果を「次を公開 ▶」で下位から1人ずつ発表する。

### ルール説明スライド
「削減アミダクジ」発表ツール（`puzzliar/amida-tools` の `present.html`）と同じ構成で、**タイトル → RULE 01〜19 → GAME START** の順に進みます。

| # | スライド | # | スライド |
| --- | --- | --- | --- |
| 01 | 目的 ― 最終得点を最も高くせよ | 11 | 周回ボーナス ― 後続人数 × 単価 |
| 02 | 初期配布 ― チップと口座 | 12 | ％奪取 ― 下位3位以内で周回した者の権利 |
| 03 | 秘匿情報 ― 駒とプレイヤーナンバー | 13 | ％奪取の不成立 |
| 04 | ボード ― 20マスの周回型 | 14 | 送受金 |
| 05 | ゲームの流れ ― 全15ターン | 15 | ペナルティ ― 無提出と周回未達成 |
| 06 | 定員 ― 基礎定員配列 | 16 | 本ゲームの勝者 |
| 07 | 同時提出 ― 進む数を秘匿で投票 | 17 | 禁止事項 |
| 08 | 開票 ― 定員以内なら成立、超えたら全滅 | 18 | ディーラーの裁定が最終決定 |
| 09 | 枠数変更カード | 19 | 質疑応答 ― 「はい」「いいえ」形式のみ |
| 10 | 順位入れ替えカード | | |

- 集計ツールの「発表画面」パネルで「ルール説明」を選び、◀ ▶ またはプルダウンで進行します。ゲーム開始前（参加者入力画面）から使えます。
- 発表画面側でも **→ / Space / Enter / クリックで次へ、← / 画面左端クリックで前へ** 進められ、集計ツールと同期します。
- 金額・単価・ターン数・人数別の基礎定員配列などの数値はゲーム設定から自動で差し込まれ、定員スライドでは選択中の人数が強調表示されます。
- 集計ツールなしで単独で使う場合は `sugoroku/display.html?rules` を開きます（既定設定の値で表示）。
- スライドの文面は `sugoroku/js/rules.js` で編集できます。禁止事項はルール資料に記載がないため、削減アミダクジに準じた一般的な内容にしています。

発表画面の表示内容は、集計ツール右側の「発表画面」パネルで切り替えます（フェーズ移行時は自動で切り替わります）。投票受付用のタイマー（5/10/15/20分）も同パネルから操作します。

> `sugoroku/index.html` を直接ダブルクリックで開いても動作しますが、ブラウザによってはウィンドウ間の同期が制限されるため、ローカルサーバー経由を推奨します。

### データの保存
- 状態はブラウザの localStorage に自動保存され、リロードしても続きから再開できます。
- 「保存」で JSON をダウンロード、「読込」で復元できます。開催中は定期的に保存しておくと安全です。
- 「元に戻す」で直前の操作を取り消せます（最大40手）。

### 情報の秘匿
発表ツールには `publicView()` が抽出した公開情報のみが送られます。**誰が何に投票したか、誰が枠数変更カードを使ったか、名前↔ナンバー↔駒の紐付け**は送信されません（最終結果の発表時のみ紐付けを公開）。集計ツールの台帳には「番号・駒を隠す」スイッチがあります。

## 実装しているルール

- 初期配布：チップ 1,000,000 L$（アイテム購入専用）、口座 2,000,000 L$
- ボード：20マス周回。基礎定員配列（12人 `[2,3,2,2,2,1]` / 13人 `[2,3,3,2,2,1]` / 14人 `[2,3,3,3,2,1]` / 15人 `[2,4,3,3,2,1]`）を毎ターンシャッフルして数字1〜6に割当
- 最終定員 = 基礎定員 + 枠数変更カード枚数。投票数 ≤ 最終定員の数字のみ成立し、その数字だけ進む。超過した数字は全員移動0（全滅・抽選なし）
- 枠数変更カード：200,000 L$（チップ）、指定数字の定員+1、重ね掛け可、当該ターンのみ、返金なし
- 順位入れ替えカード：500,000 L$（チップ）、1人1枚限り、フェーズAで公開宣言、任意の相手と位置を入れ替え。周回扱いにならない
- 周回ボーナス（バンク支給・ターン終了時）：後続人数 × 単価（1周目 50,000 / 2周目 80,000 / 3周目 120,000）
- ％奪取：周回直後に下位3位以内（3位タイを全員含む）の周回者が宣言可。対象のプレイヤーナンバー＋駒の完全一致で、対象口座の最大50%（端数切り捨て・0下限）を奪取。失敗時は周回ボーナスのみ
- 無提出：移動0。2回目以降は運営判断で口座 −100,000 L$（集計ツールで免除可）
- 終了時：1周未満のプレイヤーは口座から 1,000,000 L$ 回収。最終得点 = 口座 + チップ − 3,000,000 L$。最高得点が勝者（同点は同順位）

### ルール資料に明記がなく、運営判断として実装した解釈
資料と異なる運用をする場合は `sugoroku/js/engine.js` を調整してください。

| 論点 | 実装 |
| --- | --- |
| 位置と順位 | 各駒の「累計マス数」で順位を判定（周回数が多いほど上位）。同じ累計マス数なら同順位 |
| スタートマス | マス0＝スタート。累計マス数が20の倍数に到達・通過した時点で周回 |
| 「後続人数」 | その周回をまだ達成していない他プレイヤーの人数（移動処理後に判定）。同一ターンに同じ周回を達成した者同士は互いに数えない |
| 4周目以降の単価 | 3周目と同じ 120,000 L$ |
| 順位入れ替えの範囲 | 周回数を含めた位置（累計マス数）ごと入れ替える。入れ替えで得た周回にはボーナス・％奪取権は発生せず、同じ周回数のボーナスは1人1回まで（入れ替えで後退して再通過しても再支給しない） |
| 同時の入れ替え宣言 | GMが決めた順に1件ずつ処理 |
| ％奪取「同一対象を連続ターンで指名」 | 前ターンに誰かから指名（ナンバー＋駒が一致）された対象を、次ターンに指名すると不成立。（周回は最短でも4ターンに1回のため、宣言者単位では起こり得ないので全体で判定） |
| ％奪取の宣言額 | 宣言額は上限（対象口座の50%）で頭打ち。宣言額なしは上限額 |
| ％奪取と周回ボーナスの順序 | ％奪取を先に処理し、その後に周回ボーナスを支払う（ボーナスは「ターンの終わりに支払い」のため） |
| 口座の0下限 | ペナルティ（無提出・周回未達成）も口座残高を0未満にはしない |
| 1周未満の判定 | ゲーム終了時の位置が1周未満（累計20マス未満）か |
| 送受金 | 口座残高・チップともに、GMが記録した分だけプレイヤー間で移動（残高不足は不可） |
